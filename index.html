Perangkap Minyak — two web concepts

Two complete website directions for a Malaysian grease trap manufacturer. Same twenty-three pages, same catalogue data, same seventeen-model specification table — two different arguments about how a buyer should meet it. Both run in English and Bahasa Melayu.

Concept C

Trade Counter

A trade catalogue, not a brochure. The buyer arrives knowing roughly what they need, so every element is a route into the catalogue and the page is dense on purpose.

  • Filterable catalogue with the filter state in the URL
  • An enquiry list in place of a shopping cart
  • Scroll-scrubbed cutaway of the three chambers
Open concept C Concept D

Waterline

Navy ground, one arc motif, and a photographic hero. Built from a fixed kit of nineteen blocks, so no page invents a twentieth and the whole site keeps one grammar.

  • Meal-volume sizer that names the model as you drag
  • Jump bar built from the blocks each page actually used
  • Its own 75-check harness at checks.html
Open concept D

Both concepts share one data layer. Products, the model table, the dosing chart, services, approvals and articles all live in assets/data/, so a change to a specification appears on both sites at once.

These are design concepts. There is no backend: the enquiry form and the assistant acknowledge locally and hand off to WhatsApp, which is how enquiries actually reach this business. No prices are published, because they are quoted per installation.
